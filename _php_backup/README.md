# Клуб Бешеной Белки — CMS

Это надстройка над текущим статическим сайтом.

## Что редактируется в админке
- главная: заголовок, подзаголовок, кнопка, слоган;
- тренеры;
- услуги;
- расписание;
- галерея, включая загрузку новых изображений;
- мероприятия;
- контакты и футер.

## Установка
1. Загрузите все файлы на PHP-хостинг.
2. Откройте `/install.php`.
3. Задайте пароль администратора (минимум 10 символов).
4. После успешной установки удалите `install.php`.
5. Админка: `/admin/`.
6. Введите пароль и редактируйте сайт через интерфейс.

## Важно
Сайт должен работать именно через PHP-сервер (Apache/Nginx + PHP 8.x). Простое открытие `index.html` двойным кликом не подходит.

Данные находятся в `storage/site.json`, прямой доступ к нему закрывается `.htaccess`.

Изображения, загруженные через будущий uploader, можно хранить в `uploads/`.
