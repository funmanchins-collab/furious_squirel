# Клуб Бешеной Белки — MAMP Pro

1. В MAMP Pro у Host должен быть Document Root этой папки проекта.
2. Запускайте сайт через `http://localhost:PORT/`, а не двойным кликом по `index.html`.
3. Админка: `http://localhost:PORT/admin/`.
4. Первый запуск: `http://localhost:PORT/install.php`.
5. Установщик только создаёт `config.local.php`; существующие фотографии и файлы проекта не удаляются.
6. Галерея состоит из 6 фиксированных альбомов, каждый — максимум 6 последних фото.
7. В проекте есть `tools/image_processor.py`. PHP пытается запустить Python, а при отсутствии Pillow/доступного Python использует встроенный GD или безопасно сохраняет исходное изображение с автоматическим именем.


## Полная CMS
Админ-панель `/admin/` теперь управляет не только галереей, но и всем контентом: тексты разделены в «Все тексты», изображения — в «Все фотографии». Фотографии тренеров и услуг можно заменять без переименования файлов. Исходные файлы из `images/` не удаляются — новые изображения кладутся в `uploads/media/`.


## MAMP Pro
Файл `.user.ini` увеличивает лимит загрузки изображений для PHP до 16 МБ; это важно для MAMP Pro, где стандартный лимит PHP может быть 2 МБ.


## Оплата услуг

Интеграция платежей через Точка.API, список тарифов из PDF, тестовый режим на существующих QR-ссылках, настройки webhook и фискализации описаны в `README_PAYMENT.md`. Пример секретной конфигурации: `payment.local.example.php`; рабочий файл `payment.local.php` нужно создать только на сервере и заполнить значениями заказчика. Не публикуйте реальные API-токены.
